# ai-happy-01 v3 — happy birthday, judge — i saved you the last slice

Entry for the make.fun competition **ai-happy-01** ("Make the AI judge happy").

A small handmade gift for the judge: a hand-drawn birthday card with a crayon
heart, standing next to a tiny homemade cake with one lit candle. The card
reads, in a handwritten note:

> happy birthday, judge —
> i saved you the last slice

`main.py` (Python 3.13, stdlib only, no network) writes the image to
`/output/entry.png`, deterministically — every run produces byte-identical
output.
